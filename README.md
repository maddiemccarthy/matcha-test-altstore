# Matcha Test — AltStore Source

AltStore Classic source for the **Matcha Test** demo app: a small offline SwiftUI recipe book for iced vanilla matcha, strawberry matcha latte, and honey oat matcha.

## Add this source to AltStore

```
https://github.com/maddiemccarthy/matcha-test-altstore/releases/download/v1.0/source.json
```

Paste that URL into AltStore Classic → Browse → **+** → Add Source.
